# 기존 문제 JSON 대비 v0.1 변경 내역

기존 100문제를 기반으로 하되 아래 **5문항만 교정**했습니다. 문항 수, ID, 객관식/주관식 비율, 난이도 비율은 유지했습니다.

| ID | 수정 | 이유 |
|---|---|---|
| G1-BE-074 | `The classroom is quiet.` → `The music room is empty.` 및 정답/해설 변경 | G1-BE-044와 제시 문장 중복 |
| G1-BE-088 | `The color of these flowers ...` → `The cover of these books ...` 및 해설 변경 | G1-BE-059와 제시 문장 중복 |
| G1-BE-011 | 해설 구체화 | 설명 일관성 |
| G1-BE-061 | 해설 구체화 | 설명 일관성 |
| G1-BE-067 | 해설 구체화 | 설명 일관성 |

이는 **데이터 구조 및 표면적 중복 검증**으로, 교사 최종 문법 검수를 대체하지 않습니다.
