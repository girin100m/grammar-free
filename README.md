# 문법바로 v0.3 — 문법 단원 목록 + 슬레이트/민트 앱 아이콘

중1~중3 문법 단원 탐색 메뉴와 중1 be동사 100문제 연습장을 연결한 정적 사이트입니다.

## 무엇이 달라졌나요?
- 선택한 **슬레이트 블루 + 민트 문법바로 앱 로고**를 사이트 헤더, 홈, 파비콘, iPhone 홈 화면 아이콘에 적용했습니다.
- **중1·중2·중3 학년 탭 / 문법 이름 검색 / 분야별 강의 카드 목록**을 추가했습니다.
- **중1 be동사 100문제만 학습 가능**, 나머지는 실제 문항이 아직 없으므로 **준비 중**으로 표시합니다.
- 기존 v0.2의 문제 JSON, 객관식·주관식 채점 및 오답노트, 브라우저 학습 기록 저장 키를 변경하지 않았습니다.
- 중1 25강은 8종 교과서의 공통 문법을 통합한 초안이며, 중2·중3의 내용은 확정 전 가안입니다.

## GitHub 업데이트
1. 이 ZIP 압축을 해제한 뒤, **안에 있는 `public`, `scripts`, `tests`, `docs` 폴더와 `README.md`, `package.json` 등을** 기존 저장소 `girin100m/grammar-free` 루트에 덮어써 업로드하세요.
2. Cloudflare의 기존 Git 연동을 유지합니다.
3. **Build command** `npm run build` / **Deploy command**는 현재 성공한 설정을 유지하세요.
4. Cloudflare 빌드 성공 후 기존 `https://grammar-free.girin100m.workers.dev/`로 접속하세요. 이전 풀이 기록은 같은 브라우저에서 유지됩니다.

## 개발 중 확인
```bash
npm run validate
npm test
npm run build
npm run dev
```

## 새 문법 추가하는 법
`public/data/course-catalog.json`의 해당 강의에서 `status`를 `planned` → `available`로 바꾸기 전에 **실제 검수된 문제 JSON과 문제 풀이 연결 코드**를 준비해야 합니다. 현재의 문제 풀이/채점 로직은 be동사 은행에 고정되어 있으므로, 준비 중 카드 상태만 바꾼다고 새 단원 문제가 자동으로 연결되지는 않습니다. 다음 버전에서 범용 문항 로더로 확장하세요.

## 저작권 / 글꼴
로고는 사용자와 함께 생성하여 확정한 시안을 이미지 자산으로 사용합니다. G마켓 산스와 SUIT는 외부 웹폰트 CSS로 불러오며, 폰트 파일을 이 프로젝트에 포함하지 않습니다.
