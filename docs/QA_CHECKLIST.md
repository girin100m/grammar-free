# 교사용 최종 점검 체크리스트

- [ ] iPhone Safari / Samsung Internet / Chrome / Desktop에서 첫 화면에 10문제가 표시되는가?
- [ ] 객관식 정답/오답 및 미응답 채점이 기대대로 동작하는가?
- [ ] Q14(Mina's not tired.), Q16(she's not), Q19(Why are ... not ...) 등 허용 답안을 인정하는가?
- [ ] Q17·Q20에서 두 개의 답안 필드가 각각 표시되는가?
- [ ] 10문제씩 다음·이전 이동 시 기존 답안이 유지되는가?
- [ ] 새로고침 후 답안·채점·복습 목록이 유지되는가?
- [ ] 틀린 문제/검토 필요 문항만 재도전 모드에 표시되는가?
- [ ] 복습 모드에서 정답을 맞히면 해당 문항이 복습 목록에서 빠지는가?
- [ ] 학습 기록 JSON 내려받기와 초기화가 정상 작동하는가?
- [ ] 각 문항의 문법 정확성, 정답 유일성, 설명 수준을 교사가 최종 승인했는가?
